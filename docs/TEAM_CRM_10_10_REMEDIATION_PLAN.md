## Required shared contracts

Introduce these contracts before individual tab work:

Implementation status: the transport-safe contracts now live in `packages/sdk/src/team-contracts.ts` and are exported by `@myst-os/sdk`; the Site principal verifier and surface registry consume those shared definitions. API action-policy adoption and runtime mutation receipts remain open.

```ts
type TeamPrincipal = {
  memberId: string;
  sessionId: string;
  roleSlug: string | null;
  permissions: Permission[];
  label: string;
  authMethod: "team_session" | "break_glass";
};

type TeamSurfaceDefinition = {
  id: string;
  canonicalPath: string;
  legacyTabs: string[];
  group: "daily" | "sales" | "marketing" | "owner" | "admin" | "tools" | "personal";
  label: string;
  requiredPermissions: Permission[];
  subviews: string[];
};

type ActionPolicy = {
  principalTypes: ("human" | "service")[];
  requiredPermissions: Permission[];
  risk: "read" | "normal" | "external" | "financial" | "destructive";
  requiresIdempotency: boolean;
  auditAction: string;
};

type MutationResult<T> =
  | { ok: true; data: T; receipt: MutationReceipt }
  | {
      ok: false;
      code: "unauthorized" | "forbidden" | "conflict" | "invalid" | "rate_limited" | "timeout" | "provider_failed" | "internal";
      message: string;
      retryable: boolean;
      fieldErrors?: Record<string, string>;
    };
```

High-risk HTTP mutations require `Idempotency-Key`; record-changing requests use an expected version or `If-Match` value. Server actions carry equivalent generated values. Statuses consistently map to 401, 403, 409, 422, 429, timeout, provider failure, and internal failure.

Audit events include event and correlation IDs, verified actor snapshot, session/auth method, required permission, attempted/succeeded/denied/failed outcome, entity, safe before/after summary, idempotency key, provider operation ID, and timestamp.

External effects use a durable state machine:

```text
requested → dispatched → succeeded | failed | reconciliation_required
```
